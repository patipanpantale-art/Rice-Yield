# โฟลเดอร์ข้อมูลจังหวัดขอนแก่น (Khon Kaen Core Datasets)

โฟลเดอร์นี้รวบรวมข้อมูลทั้งหมดสำหรับการจำลองและการตัดสินใจในจังหวัดขอนแก่น ประกอบด้วย 3 โฟลเดอร์ย่อย:

## 1. `gis/` (ระบบสารสนเทศภูมิศาสตร์) - **มีครบแล้ว 100% ในระบบ**
- `landuse/`: ข้อมูลการใช้ที่ดินปี 2565 กรมพัฒนาที่ดิน (`LU_KKN_2565.shp`)
  - รหัส `A101`: นาข้าวชลประทาน
  - รหัส `A102`: นาข้าวน้ำฝน
  - รหัส `A201`: มันสำปะหลัง
  - รหัส `A202`: อ้อยโรงงาน
- `rice_zone/`: แผนที่เขตความเหมาะสมสำหรับการปลูกข้าว (`Zon_Rice_kkn.shp`)
  - `S1`: เหมาะสมสูง
  - `S2`: เหมาะสมปานกลาง
  - `S3`: เหมาะสมเล็กน้อย
  - `N`: ไม่เหมาะสม
- `soil/`: แผนที่กลุ่มชุดดินจังหวัดขอนแก่น (`soilgroup_kkn.shp`)
  - ข้อมูลเนื้อดินบน-ล่าง (`tex_top`, `tex_low`), ความอุดมสมบูรณ์ (`fer_top`), ค่าความเป็นกรด-ด่าง (`pH_top`, `pH_low`)

## 2. `statistics/` (สถิติจริงจากหน่วยงานราชการ)
ใช้สำหรับ Ground-Truth Validation และแสดงสถิติเปรียบเทียบในระดับอำเภอ/จังหวัด:
- `oae_rice_yield_khonkaen.csv` หรือ `.xlsx`: สถิติผลผลิตข้าวนาปีรายอำเภอ (26 อำเภอ) 
- `disaster_damage_records.csv` หรือ `.pdf`: สถิติพื้นที่นาข้าวเสียหายจากน้ำท่วม/ภัยแล้งย้อนหลัง

## 3. `agronomy/` (สรีรวิทยาข้าว ปุ๋ย และภัยพิบัติ)
- `rice_varieties.json`: ข้อมูลพันธุกรรมข้าว (KDML105, RD6, RD43) วันเจริญเติบโต ศักยภาพสูงสุด (Genetic Limit)
- `fertilizer_ssnm.json`: ตารางสูตรปุ๋ยสั่งตัดแยกตามกลุ่มชุดดินขอนแก่น (ดินเหนียว vs ดินทราย)
- `disaster_thresholds.json`: เกณฑ์ความเสียหายตามระยะการเจริญเติบโต (เช่น แตกกอท่วม > 10 วันตาย 100%)
