# Land Use Data Directory (โฟลเดอร์จัดเก็บข้อมูลการใช้ประโยชน์ที่ดิน)

โฟลเดอร์นี้จัดทำขึ้นสำหรับวางข้อมูลชั้นการใช้ประโยชน์ที่ดิน (Land Use / Land Cover) เพื่อใช้ตรวจสอบว่าแปลงนาที่ผู้ใช้วาดเป็นพื้นที่เกษตรกรรม/นาข้าวจริงหรือไม่ และป้องกันการวาดแปลงในเขตเมืองหรือพื้นที่ที่ไม่เหมาะสม

## รูปแบบไฟล์ที่รองรับ (Supported Formats):
1. **GeoJSON (`.geojson` หรือ `.json`)** [แนะนำที่สุด - ประมวลผลเร็ว]:
   - ตัวอย่างชื่อไฟล์: `landuse_thailand.geojson` หรือ `rice_areas.geojson`
   - พิกัด: WGS84 (EPSG:4326)
   - ฟิลด์ที่ใช้: รหัสประเภทการใช้ที่ดิน (เช่น `LU_CODE`, `LANDUSE_TYPE`, `A101`, `A102`)
2. **ESRI Shapefile (`.shp`, `.dbf`, `.shx`, `.prj`)**:
   - ต้องวางไฟล์ทั้งหมดที่มีชื่อเดียวกันครบทุกนามสกุล (อย่างน้อย `.shp`, `.dbf`, `.shx`)

## แหล่งดาวน์โหลดข้อมูลอ้างอิงของไทย:
- **กรมพัฒนาที่ดิน (LDD):** ระบบบริการข้อมูลแผนที่การใช้ที่ดิน (Land Use Map) รหัส A101 (นาข้าวชลประทาน), A102 (นาข้าวน้ำฝน), U (เขตชุมชนและสิ่งปลูกสร้าง)
- **GISTDA / GeoPlatform:** แผนที่พื้นที่ปลูกข้าวรายสัปดาห์/รายฤดูกาล
- **OpenStreetMap (OSM) Landuse:** หมวด `landuse=farmland` / `crop=rice` เทียบกับ `landuse=residential` / `landuse=commercial`
- **ESA WorldCover 10m:** ข้อมูลสากล Class 40 (Cropland)

*(หากยังไม่มีไฟล์ ระบบจะใช้กลไก Heuristic Centroid Proximity ตรวจจับขอบเขตเทศบาลนครและใจกลางอำเภอเมืองทั้ง 77 จังหวัดให้อัตโนมัติ)*
