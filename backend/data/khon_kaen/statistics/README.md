# โฟลเดอร์สถิติการเกษตรและภัยพิบัติขอนแก่น (Khon Kaen Agricultural Statistics)

กรุณานำไฟล์สถิติที่ดาวน์โหลดมาวางในโฟลเดอร์นี้:

### 1. สถิติผลผลิตข้าวนาปีรายอำเภอ (ย้อนหลัง 3-5 ปี เช่น 2564 - 2566)
- **ชื่อไฟล์แนะนำ:** `rice_yield_khonkaen_oae.csv` หรือ `.xlsx` (หรือเซฟเป็นไฟล์ PDF ที่โหลดมาก็ได้ เดี๋ยวระบบแปลงให้)
- **แหล่งดาวน์โหลด:**
  1. เว็บไซต์สำนักงานเศรษฐกิจการเกษตร (สศก. / OAE): [oae.go.th](https://www.oae.go.th/)
     - หัวข้อ: ข้อมูลการผลิตสินค้าเกษตรรายอำเภอ -> ข้าวนาปี -> จังหวัดขอนแก่น
  2. สำนักงานเศรษฐกิจการเกษตรที่ 4 ขอนแก่น (สศท.4): [zone4.oae.go.th](http://zone4.oae.go.th/)
     - รายงานภาวะเศรษฐกิจการเกษตร และสถิติข้าวประจำปี
  3. สถิติการเกษตรของประเทศไทยประจำปี (Agricultural Statistics of Thailand)
- **คอลัมน์สำคัญที่ต้องการ:**
  - อำเภอ (26 อำเภอ)
  - เนื้อที่เพาะปลูก (ไร่)
  - เนื้อที่เก็บเกี่ยว (ไร่)
  - ผลผลิตรวม (ตัน)
  - ผลผลิตเฉลี่ยต่อไร่ (กก./ไร่)

### 2. สถิติความเสียหายด้านการเกษตรจากภัยพิบัติ (อุทกภัย / ภัยแล้ง)
- **ชื่อไฟล์แนะนำ:** `disaster_damage_kkn.pdf` หรือ `.xlsx`
- **แหล่งดาวน์โหลด:**
  1. สำนักงานป้องกันและบรรเทาสาธารณภัยจังหวัดขอนแก่น (สนง.ปภ.จ.ขอนแก่น): [disaster.go.th](https://www.disaster.go.th/)
  2. รายงานสถานการณ์ภัยพิบัติด้านพืช สนง.เกษตรจังหวัดขอนแก่น (กษ.)
- **ข้อมูลที่ต้องการ:**
  - ปีที่มีน้ำท่วมใหญ่ (เช่น ปี 2564 พายุเตี้ยนหมู่ หรือ ปี 2565 พายุโนรู)
  - จำนวนพื้นที่นาข้าวที่ได้รับความเสียหายสิ้นเชิง (ไร่) และอำเภอที่ได้รับผลกระทบหนัก (เช่น อ.เมือง, อ.น้ำพอง, อ.ชนบท, อ.มัญจาคีรี)
